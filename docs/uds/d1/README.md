# UDS Tier D1 Registry Artifacts

This directory contains the public threshold artifacts for **Universal Diamond Standard (UDS) Tier D1**.

Tier D1 is the public entry point for builders, maintainers, organizations, and platforms that want to make a visible commitment to the Universal Diamond Standard without claiming audit status or full certification.

> D1 is not an audit; it is a public promise.

## Artifact set

- [`public-threshold-statement.md`](./public-threshold-statement.md) explains what D1 is, what it is not, what a signer promises, how the registry works, how drift is handled, and how Sarah AI boundaries are acknowledged.
- [`../../../schemas/uds-d1-registry-entry.v1.0.json`](../../../schemas/uds-d1-registry-entry.v1.0.json) defines the JSON Schema used to validate D1 registry entries.
- [`../../../examples/uds-d1-commitment.example.json`](../../../examples/uds-d1-commitment.example.json) provides a minimal example commitment file a project can adapt.
- [D1 Registry Submission issue form](../../../.github/ISSUE_TEMPLATE/uds-d1-registry-submission.yml) collects public self-attestations.
- [D1 Drift Report issue form](../../../.github/ISSUE_TEMPLATE/uds-d1-drift-report.yml) collects reports of operational drift, concerns, or repair needs.

## Boundary

D1 does **not** certify that a project has passed independent review. It records a voluntary commitment, supporting evidence, and a visible repair pathway.

Higher tiers may add third-party review, technical audit, accreditation, or live enforcement checks. D1 exists first so the promise can be made visible before stronger verification layers mature.
