The declared production path is:

```text
wsgi.py
  -> Genesis/o_series_app.py
  -> strict ingress validation
  -> monotonic Gate Zero
  -> isolated constitutional context
  -> conditioned persona adapter
  -> six-layer reportable output reflection
  -> metadata-only Witness Receipt
```

The deployed O-Series node is deliberately stateless, private, and text-only. It does not claim durable database-backed memory, collective learning, RTME execution, WORTH issuance/scoring, Synthocracy execution, production ZK proofs, or the legacy collective-consciousness topology.
